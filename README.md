# 局部解剖学数字化交互学习系统 (Regional Anatomy Interactive Suite)

本项目基于高等医学院校教学大纲（参考中山大学讲义）与人民卫生出版社第十版《局部解剖学》教材考点设计研发，是一套集基础精要闪卡、全景思维导图、全题库智能测评、临床病例解析于一体的数字化医学交互学习系统。

---

| :--- | :--- | :--- |

## 核心功能说明

### 1. 基础精要闪卡 (Anki 模式 · 264 卡)
- 覆盖下肢（35卡）、上肢（35卡）、头部（27卡）、颈部（27卡）、胸部（34卡）、腹部（60卡）、盆部与会阴（31卡）、脊柱背部（15卡）。
- 快捷键支持：`空格键 [Space]` 翻转卡片，`←` / `→` 切换上下张，`1` / `2` / `3` 快速评级（生疏 / 复习 / 掌握）。

### 2. 全景知识思维导图
- 树状层级梳理：涵盖各解剖分区的浅层结构、深筋膜、骨筋膜鞘、肌间隔、管道孔隙、三角及神经血管束。
- 双向考点直通：导图叶子节点带有 [考点] 标识，点击可在右侧检视器一键查阅权威解析，或一键跳转至对应闪卡进行背诵。

### 3. 题库测评系统 (1,281 题)
- 收录 A型单选题（808 题）与 X型多选题（473 题），针对脊柱区重点补充了腰穿解剖层次、椎管壁构成、神经根受压定位等高频考点。
- 题目附带 [关联考点] 标签，支持“做题排查薄弱点 -> 立即弹窗背诵”的高效闭环。

### 4. 临床病例分析 (143 例)
- 收录各大解剖分区经典病例，提供患者主诉、病史、查体表现及临床解剖学思考题。
- 支持“回忆构思 -> 展开答案”模式，补充了权威解剖学发病机理与临床要点提炼。

## 运行与多端使用

### 1. 电脑桌面直接运行（推荐）
- 双击运行根目录下的 `局部解剖学学习系统.exe`（23 KB 原生独立轻量程序，无地址栏全屏体验）。
- 或双击运行 `打开学习系统.bat`，亦可直接使用任何现代浏览器双击打开 `index.html`。

### 2. 手机与平板端使用（PWA 离线模式 · 推荐）
系统支持 PWA 标准与 Service Worker 离线强缓存：
1. 双击运行 `启动手机局域网同步.bat`，控制台将显示本机局域网 IP（如 `http://192.168.x.x:8080`）。
2. 手机连接同一 Wi-Fi，在手机浏览器中打开该地址。
3. 点击浏览器菜单中的 [添加到主屏幕] 或 [安装应用]，桌面即可生成独立的《局部解剖学》App 图标。
4. 应用内置离线缓存，打开一次后断网亦可顺畅使用全部功能。

### 3. 独立 APK 安装包制作与导出
- **免命令行一键打包（推荐）**：双击运行 `打包APK助手.bat`，支持在窗口中一键定位 637 KB 专用离线包并直达在线打包平台，30 秒扫码出 APK；或一键推送到 GitHub 触发云端自动编译。
- **Android Studio 本地编译**：根目录下的 `android/` 文件夹为标准 Android Studio 原生工程，使用 Android Studio 打开后点击 `Build` -> `Build APK(s)` 即可生成 APK。

## GitHub 仓库更新与代码维护

系统已内置 Git 与 GitHub Actions 自动化构建脚本：

### 一键更新 GitHub 仓库
双击运行根目录下的 `更新GitHub仓库.bat`：
1. 脚本将自动将最新代码同步至 Android 静态资源目录。
2. 自动执行 `git add`、本地 `commit` 与推送至 GitHub 远程分支。
3. 推送完成后，GitHub Actions 将自动触发云端编译，直接在仓库的 Actions 页面生成最新的 `RegionalAnatomy-debug.apk`。
