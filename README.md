# 中山大学《局部解剖学》数字化交互学习系统 (SYSU Regional Anatomy Interactive Suite)

本项目基于**中山大学局部解剖学学习资料讲义**精心转化与研发，构建了一套集**基础精要闪卡（Anki模式 · 264卡）**、**全景知识思维导图（层级展开折叠与双向考点联动）**、**全题库智能测评（1,281题 · 单选/多选/解析/考点穿梭）**、**临床病例解析（143例 · 回忆构思后展开权威解答）**、**智能错题本**、**重点题目收藏夹**与**轻量级独立桌面程序（.exe 封装）**于一体的现代化医学交互学习系统。

---

## 🌟 核心功能特色

### 1. 🎴 章节基础知识学习（Anki 3D 沉浸式闪卡 · 扩充至 264 张）
- **海量考点全覆盖**：从原先的 45 张大幅扩充至 **264 张系统化闪卡**，细化到各肌群肌腱排列、神经分支走向、血管毗邻、体表投影、筋膜鞘构成、孔隙边界与经典记忆口诀（如 Tom, Dick And Very Nervous Harry）。
- **3D 翻转交互**：正面展示引导性考点提问与解剖标志，点击卡片或轻按**空格键 [Space]** 平滑翻转查看背面结构毗邻与精炼口诀。
- **艾宾浩斯间隔复习打分**：
  - `生疏 (快捷键 1)`：标记为生疏，归入需巩固队列。
  - `复习 (快捷键 2)`：标记为普通复习。
  - `掌握 (快捷键 3)`：标记为熟练掌握，自动计入掌握进度条。
- **快捷键完全支持**：
  - `←` / `→`：切换上一张 / 下一张闪卡。
  - `空格 [Space]`：翻转卡片。
  - `1 / 2 / 3`：生疏 / 复习 / 掌握快速评级。

### 2. 🌳 全景知识思维导图系统 (264张闪卡 100% 完整融入映射)
- **264 张闪卡考点全量入网**：全系统全部 264 个闪卡考点已 **100% 逐一结构化映射**至思维导图对应章节的分区树状叶子节点（下肢 35 考点、上肢 35 考点、头部 27 考点、颈部 27 考点、胸部 34 考点、腹部 60 考点、盆部与会阴 31 考点、脊柱背部 15 考点），绝无遗漏！
- **多层级树状全景图谱**：按人体八大解剖分区建立结构化层级分支，涵盖浅层结构、深筋膜、骨筋膜鞘、肌间隔、管道裂孔、重要三角及神经血管束。
- **交互式展开与折叠**：支持逐级点击节点展开/折叠，亦可使用工具栏「全部展开」与「全部折叠」进行全局概览。
- **双向考点直通弹窗 (Inspector)**：点击思维导图上的任意闪卡考点节点，右侧面板即刻展示其解剖特征与毗邻关系，并提供**一键直通按钮**：
  - 点击「查看考点详细解析」：呼出弹窗展示标准解剖学要点。
  - 点击「前往闪卡背诵此考点」：直接跳转至对应闪卡进行背诵评分。

### 3. 📝 题库测评与检测系统 (1,281 道全量试题 · 脊柱区深度扩补)
- **完整讲义题库**：全量收录原讲义及教研室精选题库共 **1,281 道题目**（A型最佳单选题 808 道 + X型多选题 473 道）。
- **针对脊柱区题目断页的专业补全**：原打印版 PDF 因扫描打印缺陷在第 137 页仅有 2 题便直接跳跃至第 149 页；本系统特依据中山医局解教学大纲与《脊柱篇试题详解》深度补全了 **40 道高质量脊柱区考题**（包括体表骨性标志、听诊三角/腰上三角/腰下三角/枕下三角、椎管壁构成、黄韧带力学特点、脊髓圆锥与终池马尾、腰椎穿刺 7 层路径与两次落空感机制、L4/L5 及 L5/S1 椎间盘脱出神经根受压定位、直腿抬高试验等核心高频必考点）。
- **即时与交卷交互模式**：
  - **A型单选题**：点击选项即时判定对错，正确高亮翠绿，选错即时标红并高亮官方正解，错题自动加入错题本。
  - **X型多选题**：多选复选框自由勾选，点击「提交多选答案」后进行组合智能判定。
- **考点双向穿梭联动**：
  - 题目下方自动配备专属「关联核心考点」标签（如 `[考点: 腰椎穿刺穿经7层解剖层次]`）。
  - 点击即可呼出知识卡片浮窗进行原理精读，更支持一键「前往闪卡背诵此考点」，实现“做题发现薄弱点 → 立即背诵基础知识”的高效闭环。
- **极致流畅性能**：采用每页 20 题智能虚拟化分页渲染，DOM 节点极度轻量，滚屏达到 120fps 丝滑水准，彻底杜绝卡顿。

### 4. 🩺 临床病例综合分析（Clinical Cases Recall & Reveal · 143 例）
- **完整收录 143 个经典临床病例**（覆盖下肢 21 例、上肢 20 例、头部 21 例、颈部 18 例、胸部 12 例、腹部 21 例、盆部与会阴 17 例、背部 13 例）。
- **回忆再展开模式**：页面展示患者主诉、病史、体征及临床解剖学思考题；使用者先在脑海中回忆构思诊断与受损神经血管，之后点击「展开权威解剖学答案与机制解析」抽屉，查看全套医学级权威诊断与机制解答。
- **独家补充权威解答**：针对原讲义中未提供病例答案的问题，全面补充了精准的解剖学机理解释、神经受压体征、骨折移位力学机制、手术切口禁忌及「临床要点提炼 (Clinical Pearl)」。

### 5. ❌ 智能错题本 (Error Notebook)
- 答错的题目自动入库，并在顶部导航栏显示实时错题角标。
- 支持按章节专项攻克错题。
- 做对后支持一键「移出错题本」，也可一键清空错题本。

### 6. ⭐ 重点题目收藏夹 (Favorites)
- 每道题目右上角均有星标按钮，随时收藏难题、易错题与经典综合题。
- 在收藏夹中集中攻克，复习效率翻倍。

### 7. 📊 学习数据中心与档案本地持久化
- 实时统计：已刷题数、总体正确率、闪卡掌握率、错题数、收藏数。
- **数据本地持久化**：所有学习进度自动保存在独立存储（LocalStorage）中，关机重开不丢失。
- **备份与迁移**：支持一键「导出学习档案 (JSON)」和「导入学习档案 (JSON)」。

### 8. 🎨 极简现代医学 UI 与矢量矢量图标
- 遵循严谨、专业的医学数字教材规范，完全去除 Emoji 图标，全面替换为细腻的 SVG 矢量图标。
- 支持优雅的深色模式（Dark Mode）与护眼浅色模式一键切换。

## 🚀 启动与使用方式

### 方式一：独立桌面应用程序（推荐）
- 直接双击运行根目录下的 **`局部解剖学学习系统.exe`**。
- **特点**：
  - 体积极小（仅 23 KB），采用 Windows 原生 C# 编译。
  - 启动无多余黑框控制台，无浏览器地址栏与标签页干扰，全屏无框沉浸式体验。
  - 自带专属应用数据存储隔离，保证刷题进度和错题记录持久化。

### 方式二：一键脚本启动
- 双击运行 **`打开学习系统.bat`**。

### 方式四：📱 安卓手机/平板端一键安装（PWA 原生全屏模式 · 强烈推荐）
本系统已完整实现 **Progressive Web App (PWA)** 标准及 **Service Worker 离线强缓存引擎**：
1. 双击运行根目录下的 **`启动手机局域网同步.bat`**。
2. 确保手机与电脑连接同一 Wi-Fi，控制台会自动列出您的局域网网址（例如 `http://172.29.58.249:8080`）。
3. 用手机浏览器（Chrome、Edge、华为浏览器、小米浏览器、夸克、Via等）打开该网址。
4. 点击浏览器菜单中的 **「添加到主屏幕」** 或 **「安装应用」**：
   - 手机桌面上会立刻生成专属 **《局部解剖学》** 独立 App 图标！
   - 点击打开即为纯正全屏原生界面（无浏览器地址栏、无标签干扰），适配手机刘海安全区。
   - **100% 离线可用**：Service Worker 已将全部 264 张闪卡、思维导图、1,281 道试题及 143 例病例缓存在手机本地。即使电脑关机或手机处于飞行模式，依然能丝滑离线学习！

### 方式五：📦 打包为独立 Android APK 安装包
系统在 `android/` 目录中已预置了标准 Android Studio 原生 WebView 工程架构与 GitHub Actions 自动化编译工作流：
1. **GitHub Actions 自动化云端 1 键打包**：
   - 将本项目推送到个人的 GitHub 仓库，根目录已配置 `.github/workflows/build-apk.yml`。
   - GitHub Actions 虚拟机会全自动调用 Android SDK 编译出 `RegionalAnatomy-debug.apk`，在 Actions 页面直接点击下载即可安装到手机！
2. **Android Studio 本地直接编译**：
   - 使用 Android Studio 打开根目录下的 `android/` 文件夹。
   - 点击顶部菜单 `Build` -> `Build Bundle(s) / APK(s)` -> `Build APK(s)`，即可在 `android/app/build/outputs/apk/` 下生成 apk 文件。
3. **第三方绿色 Web-to-APK 快速生成**：
   - 亦可直接使用经典的免费绿色工具（如 Website 2 APK Builder 绿色版，或 PWABuilder 在线转换），载入本文件夹直接一键生成独立 `.apk` 文件。
